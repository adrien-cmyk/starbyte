PRENDRE LE LARGE

Un même univers.
Votre propre point de départ.

Déplacez-vous dans un volume stellaire généré par un champ fractal commun. Les secteurs existent dans les adresses, sans contours dessinés ni arrêt à leurs limites.

Tourner autour du point viséGlisser · 1 doigt
Déplacer le point viséMaj + glisser · 2 doigts
Avancer / reculerMolette · pincer · + / −
Explorer librementZQSD / WASD · flèches
Monter / descendreR / F

  • Navigation : choisissez un départ et une destination par nom ou par adresse, comparez le vol libre et les corridors, puis lancez le voyage en un ordre.
  • Les corridors, jonctions, relais et valeurs de vitesse ou d’énergie sont une proposition à valider. Les stations gardent leur nom et leur adresse.
  • Chaque secteur contient exactement 9 999 systèmes ; chaque amas regroupe 26 secteurs.
  • Approchez un système pour afficher ses 99 spots sur une grille hexagonale locale.
  • Les systèmes contiennent 0 à 3 planètes. Les deux mondes de départ sont réservés pour la démonstration.
  • Changer de joueur déplace la caméra ; les lieux conservent leurs positions.
  • « Sonder » simule une découverte locale. Il n’y a ni serveur, ni flotte, ni sauvegarde de partie.

La fenêtre chargée est finie et se renouvelle pendant le déplacement. L’espace est extensible ; cette démo borne ses adresses aux coordonnées de secteurs ±10 000 pour conserver une précision numérique documentée.

Le rendu 3D n’a pas démarré.

Ouvrez ce fichier dans un navigateur compatible WebGL.
